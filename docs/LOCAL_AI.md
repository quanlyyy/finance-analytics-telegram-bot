# Локальный голос, чеки и чат

Платные API и ключи не нужны. Используются готовые открытые модели: faster-whisper base (русская речь, CPU int8), Tesseract rus+eng (фото чеков), Qwen3 0.6B через Ollama (чат). Это не обучение собственной модели с нуля.

## Пользователю

- Боту можно отправить голосовое до 30 секунд или фото чека до 6 МБ. Сумма и категория сохраняются только после нажатия «Сохранить». При ошибке отмените черновик и отправьте исправленный текст. Черновик действителен 24 часа; повторное нажатие не создаёт дубликат.
- В мини-приложении есть «Распознавание»: загрузите аудиофайл или JPEG/PNG/WebP, исправьте поля и подтвердите. Дата по умолчанию сегодняшняя — для старого чека измените её.
- «ИИ-чат» и команда `/ask вопрос` дают ответ по личной сводке месяца. В приложении учитывается выбранный месяц, в боте — текущий. История чата только в открытой вкладке; последние два обмена текущего месяца отправляются для контекста. Чат не изменяет операции.
- Небольшая модель может давать неточные или неудачно сформулированные ответы. Суммы проверяйте в аналитике. Один запрос обрабатывается за раз; при занятости повторите позже. Максимальное ожидание около трёх минут с учётом загрузки файла.
- OCR ищет итоговую сумму, не разбивает чек на отдельные товары. При неоднозначности сумму нужно указать вручную. Несколько расходов в одном голосовом не поддерживаются.

## Установка на VPS

Команды из корня проекта, существующий `.env` не перезаписывать. Основной режим бота — `BOT_MODE=polling`.

```sh
docker compose -f compose.yaml -f compose.local-ai.yaml build ai-worker
docker compose -f compose.yaml -f compose.local-ai.yaml up -d ollama
docker compose -f compose.yaml -f compose.local-ai.yaml exec -T ollama ollama pull qwen3:0.6b
docker compose -f compose.yaml -f compose.local-ai.yaml run --rm ai-worker python download_models.py
docker compose -f compose.yaml -f compose.local-ai.yaml up -d --wait ai-worker
docker compose -f compose.yaml -f compose.local-ai.yaml --profile polling up -d --build api bot caddy
```

**При каждом обновлении используйте оба compose-файла.** Без второго файла API не получит адрес обработчика. Модели сохраняются в `speech-models` и `chat-models`. Порты Ollama и обработчика не публикуются. Контейнеры автоматически перезапускаются. На VPS с 2 ГБ это режим для небольшой нагрузки. Для загрузки Docker-образов требуется около 13 ГБ свободного диска.

## Данные и ограничения

Файлы передаются из Telegram или приложения на этот VPS, обрабатываются во временном каталоге и удаляются после запроса. Внешние AI API не получают пользовательские данные. Telegram продолжает хранить отправленные ему сообщения согласно своим правилам. В SQLite хранятся подтверждённые операции и временные черновики Telegram (удаляются при обработке, при удалении данных пользователя или при создании следующего черновика после истечения срока). Истёкшие черновики могут оставаться в резервных копиях базы.

ИИ получает только сводку своего пользователя; идентификатор берётся из проверенной Telegram-авторизации. Исходные записи и заметки в чат не передаются. Обработчик ограничивает файл 6 МБ, изображение 12 млн пикселей, аудио 30 сек; один активный запрос и пауза 8 сек на пользователя. Лимиты контейнеров ограничивают потребление памяти. При нехватке ресурсов запрос завершается ошибкой без сохранения операции.

## Проверка и откат

`python -m pytest -q` и `pnpm build` в frontend. Синтетические проверки: `scripts/smoke_local_ai.py` выполняется в ai-worker; `scripts/smoke_voice.py` дополнительно требует piper-tts только для генерации тестовой речи. Они не создают финансовые записи.

Перед обновлением: `docker compose exec -T api python -m scripts.backup`. Сохраняйте старые образы API/бота тегом. Для отката запустите предыдущие образы с тем же томом базы; добавленная таблица recognition_drafts не меняет существующие таблицы. Не выполняйте `down -v`. Обработчик можно остановить отдельно: старые функции продолжат работать, новые покажут недоступность.

Источники моделей: https://github.com/SYSTRAN/faster-whisper, https://tesseract-ocr.github.io/tessdoc/, https://ollama.com/library/qwen3:0.6b.
